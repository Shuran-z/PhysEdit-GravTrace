## 对 CVPR 实验设计的影响

当前识别出的完整三分支组在 val 和 ID test 中均为零。现有划分可以继续服务其声明的用途，但不能直接提供完整的 ID 三分支测试。不能从已调优 train 移几个组、改名后声称未见测试。

应先核对所有开发访问，再决定新增未见参数配置、未访问来源组的补充测试，或明确限定为现有模板留出评测。T07 的 180 个 Genesis、20 个 Isaac 完整组保持 OOD 身份；本轮没有把它们加入开发核验清单。

对 VideoPhysEdit 的规模比较应分别列视频、轨迹、有效干预组与实际评测任务。这里的 1,330 是三分支候选组，不能直接当作该工作的 129 个编辑任务的同口径倍数。后续核验可以给出有多少可执行且科学有效的成对任务。

## 首批核验清单

`huggingface_train_review.jsonl` 已固定 44 组：Genesis 30 组、Isaac 14 组。Genesis 部分覆盖 T01/T02/T04/T05/T08/T15 六类与五档重力，共 90 条轨迹。每个引擎、事件、重力组合按候选 ID 排序取首个满足结构条件的 train 组；选择不读取误差、实际分支或视觉质量。

清单附 cam01 视频、旁文件或配置的引用与固定来源身份。它用于元数据与媒体核验，不是已通过 QA 的生成任务队列。先完成 Genesis 的 30 组，Isaac 留作对照核验。主清单未改动，未启动下载或远程计算。

每组需要记录以下事实，才能晋升为正式干预组：

1. 三个成员的真实干预参数、数值与单位；配置值和运行回读一致。
2. 其余初态、物体属性、触发、相机与时间设置是否按任务要求固定；差异有明确解释。
3. 从轨迹、接触及视频得到的实际结果和关键事件顺序。不能从文件名生成 observed_outcome。
4. 分支是否跨越结果分界；若没有跨越，保留为同结果控制或参数响应样本，不能虚称成功分岔。
5. 三个视频是否可解码、目标和关键事件可见、物体身份可辨。区分有效静止分支与触发失败。
6. 输入只包含应提供的初态和参数，不在提示词中透露被测试的结果；记录哪些隐藏条件由文字或源视频提供。

数值参数范围、真实跨分界比例和事件标签准确率均未由本次命名审计确定。它们是下一步核验的输出，不用旧版设计合同代替实际测量。

## 复现与验证

在仓库根目录运行：

```powershell
python scripts/phyediting_intervention_audit.py --out docs/intervention_audit_2026-10-09
python -m unittest discover -s tests -p test_intervention_audit.py -v
```

脚本只读取本地数据清单和已有开发暴露审计，输出汇总、全部候选索引、train 核验清单。JSON 汇总保留输入文件 SHA-256；全部候选可按 record_id 回溯源清单。已通过 7 项测试，覆盖跨版本/背景/重力误配、重复分支、跨 split、缺元数据、重复背景计数及未知重复编号等情况。另核验了输出 ID 唯一、核验清单全部属于 train、每组恰有三成员和 cam01 路径。
