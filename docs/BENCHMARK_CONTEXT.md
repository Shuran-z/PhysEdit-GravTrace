## 整体定位和分工

“物理数据集”位于 `D:/sysu/大三/物理数据集`；本仓库位于其下的 `PhysEdit-GravTrace`。

整体工作覆盖物理场景与数据构建、参数干预和反事实设计、生成模型运行、物理评测及泛化测试。GravTrace 是其中量化视频有效重力的核心模块之一，不代表所有物理机制或所有样本的评估已经完成。

| 部分 | 已有内容及职责 |
|---|---|
| 数据集项目 | 日常物理交互与因果事件链、受控参数、临界分支反事实、Genesis/Isaac 数据、同步多视角、状态及事件记录、版本和质量审计、数据划分 |
| 本仓库 `physedit/` | 视频模型配置和 runner、远程生成调度、产物回收与评测阶段编排 |
| 本仓库 `gravtrace/` | 根据声明的场景条件和视频观测，通过物理运动与相机投影拟合重力，并报告拟合状态和评分 |
| 本仓库 `scripts/` | 数据提取、校准、窗口构造、SAM2 跟踪、生成评分、基线和误差诊断 |

整体研究问题可以围绕“视频模型能否响应物理参数干预，并保持正确的因果演化和可测量的动力学”组织。此表述是当前综合定位建议，不表示用户已最终确定论文标题、全部任务或指标。

## 数据侧已建立的基础

依据父项目的数据说明、历史项目记忆和 `dataset_splits_v2/README.md`：

- 设计覆盖 T01–T20 日常物理事件、四背景、五档重力和三个同步机位；三机位来自同一次物理轨迹。
- 设计包含全局参数扫描，以及围绕 A/B/C 单变量因果分界的 `theta- / theta* / theta+` 反事实分支和重复样本。不同事件和历史版本的实际实现需以各自配置合同核实。
- 参数和监督不只有重力，也包括初速度、摩擦、几何/支撑条件、质量等事件相关条件，以及位置、姿态、速度、接触和事件结果。
- Genesis 和 Isaac 提供跨引擎数据基础；不据此预设所有场景均已形成严格物理配对。
- Genesis 的 52,800 视频 / 17,600 轨迹是完整合同设计规模，不能直接作为当前正式有效样本数。

## GravTrace 子模块的当前证据

- 1,038 条是反演指标的筛选开发集，不能作为整体 benchmark 的规模或独立测试集。
- 默认仍为 anchor；centred 为实验设置。已知速度原筛选集约 1.11% 平均误差、6.2% 最大误差。
- 未知速度、30 fps 共同观测帧实验约 2.909% 平均误差、26.482% 最大误差；15 fps 存在 193/1,038 条帧不足。具体口径以实验报告为准，不混用不同设置的成绩。
- 生成评分已使用未知初速度协议，但仍依赖声明位置、姿态及参考窗口等，不是纯 video-only 评测。
- 最新本地记录：VGGT 的 502 条共同输入重推理已完成，加 534 条完全同输入复用；有界未知速度结果 981/1,038 成功，均值 46.881%、最大 576.514%。旧 42.860% 为历史缓存结果。五种单帧深度模型 1,036/1,036 输入匹配，表示与损失单位差异仍存在。不要重复启动这批任务。
- 15 fps 失败已拆为 191 条窗口采样容量不足、2 条缺跟踪帧。同对象跨窗口 12 条开发试验均值 5.804%→8.217%、最大 14.428%→60.905%，未改善，不作为正式修复。
- 1,038 个开发观测仅覆盖 T03/T08/T17/T18/T19/T20；其中按 ID 匹配的 432 条来自旧扫描版，不能把其成绩直接等同最终正式 core release 的成绩。

## 对投稿判断的修正

之前只围绕 GravTrace 的最小二乘拟合和 1,038 条开发数据讨论 AAAI/CVPR，低估了数据侧的独立贡献。后续应按“数据与干预设计 + 评测协议与指标 + 模型行为及泛化证据”的整体工作判断。

有潜力形成的贡献包括：日常多物体因果链及临界反事实数据；物理参数可控生成的可量化评测；模板 OOD 和跨引擎迁移测试。贡献成立仍需与近邻工作对照并完成实验证明，不能仅凭数据规模或双引擎设计推断录用前景。

当前应优先检查：正式数据版本与质量边界；整体任务和指标覆盖；独立测试与指标调优隔离；生成视频上反演指标的适用性；公平基线与来源组级统计。重力反演无法覆盖的接触、摩擦、因果分支等，需要明确已有指标和待实现指标，不能声称一个重力分数衡量全部物理正确性。

2026-10-09 CVPR 路线建议：将受控参数干预、临界分支和后续事件评测作为整体主线，GravTrace 为数值诊断模块；这是建议而非已完成贡献。当前生成 EVENTS 提示词包含后续结果，只能支撑对应的控制任务，不能直接证明无结局提示的因果推断。需要单独冻结因果任务协议、核实输入可辨识性、真实分支与单变量关系，并验证生成视频的分支评分。优先完成这些证据，不让论文全部等待开发集最大误差≤10%。

CVPR 2027 官方截止：2026-11-10 注册、11-16 正文、11-23 补充材料，均 AoE。2026-10-09 查询的 CFP 明确 9 月 15 日后公开的工作通常属同期工作，仍需引用讨论并尽可能比较；9 月 28 日公开的 VideoPhysEdit 落在此范围。后续使用前核对官方更新。
